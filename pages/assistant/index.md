# Eric Personal Assistant

A private assistant operated by Eric Norman for personal email follow-through and calendar preparation.

The assistant runs on Eric's own computer using OpenClaw. With permission, it reads connected Google accounts to identify conversations awaiting a reply, organize follow-up tasks, and prepare for upcoming calendar events. It keeps working notes and proposed next steps for Eric to review.

The current Google integration requests read-only Gmail and Google Calendar access. It does not send email, change mailbox labels, delete messages, or create or change calendar events. Any future write capability requires separate authorization.

This website provides information about the integration. It does not provide access to the assistant, email, calendar, or private task records. The assistant is for personal use and is not offered as a public service.

Relevant email and calendar content can be processed by OpenAI models to help interpret requests and prepare summaries. Read the [privacy policy](/assistant/privacy/) for details about data access, processing, storage, and revocation.
